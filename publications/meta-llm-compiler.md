# Meta Large Language Model Compiler: Foundation Models of Compiler Optimization

| Field | Value |
|---|---|

| **Type** | paper |
| **Group** | Foundation LLMs for compilers |

## Key contributions

- Open foundation models on 546B IR/asm tokens
- Instruction tuning for compiler emulation
- FTD models for size optimization and disassembly

## Summary

Code-Llama-based foundation models specialized for compiler IR/assembly reasoning; fine-tunes achieve a large fraction of autotuning size gains without iterative compiles.

## Key takeaways

- Best starting checkpoint family for IR tasks
- Disassembly still limited exact-match
- Released to accelerate community research (CC'25)
