## Summary

Makes compilers first-class participants during LLM decoding by diagnosing partial programs early, reducing error cascades.

## Key takeaways

- Reshapes when compilation happens in AI coding
- Especially valuable for strict languages like Rust
- Different from pass-ordering papers: frontend generative loop
