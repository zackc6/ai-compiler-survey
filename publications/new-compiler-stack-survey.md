## Key contributions

- Multi-dimensional taxonomy: Selector / Translator / Generator
- Maps LLM methodology, abstraction level, and task type
- Argues hybrid systems are the most promising path

## Summary

Systematic survey of LLM-enabled compilation. Frames how LLMs integrate into compilers and highlights correctness/scalability as central challenges.

## Key takeaways

- Use Selector/Translator/Generator when classifying new work
- Hybrid validation beats free-form LLM rewrite
- Good roadmap paper for onboarding
