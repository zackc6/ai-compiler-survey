## Key contributions

- End-to-end DL compiler stack
- Graph + tensor lowering with autotuning hooks
- Open ecosystem that seeded AutoTVM/Ansor

## Summary

Foundational system paper for compiling deep learning workloads across hardware with automated optimization.

## Key takeaways

- Baseline for all later neural/LLM compiler work
- Separates graph opts from tensor schedules
- Still the conceptual ancestor of many stacks
