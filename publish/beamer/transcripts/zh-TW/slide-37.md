# 幻燈片 37：附錄 — 證據圖

附錄總覽——三個桶。幻燈片上：Publications、Products、Repositories 三欄。口播：幫聽眾定位；解釋分級與 ★ 標記。

**文獻摘要（129 筆）。**
每個來源一個檔案——論文、部落格、演講、forge 頁、會議紀錄。★ = 預測關鍵：直接影響 C1–C10、阻礙或 T1–T10 的機制。不是每篇文獻摘要都同等；衝突活著時先讀星號。

**產品 — 商業 SKU 作為預測訊號。**
A 級證據形塑混合未來長什麼樣——智慧體迴圈、核心表面、會改編譯工作流的雲智慧體產品。B 級證據 = 智慧體必須插入的資料面預設：Inductor、XLA/StableHLO、TensorRT-LLM、FlashInfer 執行期等。不是完整 SKU 清單——為預測而策劃。

**儲存庫 — forge 上的 A/B/C 級產物。**
GitHub、Gerrit 與其他 forge。A 級證據 = 智慧體 + 領域判定預言機改啟發式、核心、旋鈕或審查（Magellan、CompileIQ、GEAK 類）。B 級證據 = 資料面宿主。C 級證據 = 只有通用 forge AI——預測時降級（C7）。

**何時翻這張。**
有人問「X 的證據在哪？」——指向桶與層。有爭議的檢查點 → 只看 ★ 文獻摘要 + A 級證據。不要拿 C 級儲存庫當編譯器智慧體結算。

收尾：三個桶，兩個優先（★ 與 A 級證據）。其餘都是上下文。
