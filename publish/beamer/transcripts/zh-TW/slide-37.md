# 幻燈片 37：附錄 — 證據圖

附錄概述——三個桶。幻燈片：出版物、產品、儲存庫列。口語：引導聽眾；解釋等級和 ★ 標記。

**出版物（~115 文獻摘要）。**
每個來源一個檔案——論文、部落格、演講、偽造頁面、會議紀要。 ★ = 預測關鍵：直接影響 C1–C10、阻滯劑或 T1–T10 的機制。並非所有的文學論文都是平等的；星號條目是衝突發生時您首先閱讀的條目。

**產品 — 商業 SKU 作為預測訊號。**
級別證據塑造了混合未來的樣子——智慧體迴圈、核心表面、改變編譯工作流程的雲智慧體產品。 B 級證據 = 資料平面預設值智慧體必須插入：Inductor、XLA/StableHLO、TensorRT-LLM、FlashInfer 執行時等。不是完整的 SKU 列表 - 為預測而策劃。

**儲存庫 — 鍛造 A/B/C 級工件。**
GitHub、Gerrit 和其他偽造品。 A 級證據 = 智慧體 + 域決定機更改啟發式、核心、旋鈕或審查（Magellan、CompileIQ、GEAK 類）。 B 級證據 = 資料平面主機。 C 級證據 = 僅通用鍛造 AI — 降級用於預測 (C7)。

**何時接觸這張幻燈片。**
有人問“X的證據在哪裡？” — 指向桶和層。有爭議的檢查點 → 僅限 ★ 文獻摘要 + A 級證據。不要引用 C 級證據儲存庫作為編譯器智慧體解決方案。

結束線：三個桶，兩個優先順序（★ 和 A 級證據）。其他一切都是上下文。
