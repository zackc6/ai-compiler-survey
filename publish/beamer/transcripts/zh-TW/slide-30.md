# 幻燈片 30：技術預測 — 每個檢查點需要什麼

技術到檢查點圖。幻燈片上：每個衝突 ID 的頻段，帶有來自技術的箭頭。口語：對於每個檢查點，說出技術以及“解決”的樣子——貫穿始終的混合精益。

**C1 ← T4 — 啟發式 vs 神經顧問。**
需要 Magellan 級綜合 *或* EmitC-MLGO 客戶預設指定應用程式。到 2027 年，每季度觀看公共 llvm 補丁和 OpenEvolve 配方。平行投注保持平行，直到證據選擇預設值。

**C2 ← T3 + T6 + T8 — 中值/p90 增益。**
需要可重玩的工件（T3 ACF凍結），服務判定預測機（T6）和完整的梯子（T8）。 FlashInfer-Bench 是壓力，而不是結算 — 固定痕跡 + p50/p90 + 編譯成本 + 服務穩定性。

**C5 ← T1 + T3 — 發行說明中的預設路徑。**
需要型別化介面以及釋出版本說明中指定的 freeze-before-serve。 ACF 工作流程和控制檔案成為記錄的預設值，而不是隱藏標誌。

**C3 / C6 ← T1 + T2 — 介面寬度和混合。**
C3：自由重寫與諮詢 — 精益是受限工具 + ACFs/提示 (T1)，而不是廣泛重寫 API。 C6：替換 vs 控制面 — 精益是 C6-B 混合體：承認/回退路徑 (T2)，經典的降低停留。翻轉訊號：生產預設情況下*不*經典承認意味著智慧體取代了編譯器 - 調查透過 Horizon B 拒絕了這一點。

**C9 ← T5 + T8 — 覆蓋範圍與峰值。**
需要覆蓋範圍→效能智慧體加上方言接收器和第二供應商 TritorX 級公共劇本。 SKU 故事：覆蓋 SLA（服務水平協議）第一，效能 SLA 第二。

**C10 ← T5 — 軟硬體良好設計與自動流片。**
需要 ISA/方言*僅提案*——人類和晶片設計工具擁有流片。 今天的智慧體強調核心和IR；沒有聲稱自主微架構。

結束線：每個檢查點都是可證偽的。將您的路線圖投資對映到 T 行；不要資助那些不連線到您願意關注的檢查點的技術。
