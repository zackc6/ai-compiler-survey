# 幻燈片 8：架構 — 目標堆疊

從上到下建這張堆疊——架構章節其餘部分的參考圖。邊講邊指每一層帶。

**人類／產品意圖（頂部）。**
邊緣的自然語言、政策、預算——產品要什麼（延遲 **SLO**（服務水準目標）；每 token 成本；品質門檻）。意圖不會直接編譯；它約束控制面。

**智慧體控制面（鋼色層帶）。**
工作 **(a)–(d)** 都在這裡。底層包括工作流程編譯（智慧體步驟的離線圖）、執行前的 **ADG**（智慧體相依圖）檢查、**freeze** 以確定性重播，以及異質 **place**（跨裝置／機群的放置）。型別化工具與 admit 閘門向下連接——幻燈片箭頭標籤：*typed tools · admit · oracles*。

**經典資料面（琥珀色層帶）— 預設路徑保留。**
框架 → Inductor / XLA / **MLIR** / Triton / Tile / CuTe。合法性、lowering、admit／fallback。這在預測裡沒有被棄用——它會因智慧體可定址介面而變厚。接下來幾張會展開 **多層帶 L1–L7** 盤點，以及為什麼單一通用成本模型行不通。

**三片葉子 — 產物與執行時。**
- **GPU / NPU / ASIC** — sim → 矽片執行目標。
- **VCS 產物** — 控制檔、**ACF**（進階控制檔／CompileIQ 控制產物）、核心、記憶體規劃；智慧體跑完後你在 git 裡 diff 的東西。
- **服務執行時** — freeze 以重播；生產路徑必須重現離線 admit 決策。

**協同設計回饋（餘燼色層帶）。**
從矽片回圈到 ISA／方言 RFC。人類與晶片 EDA 工具仍擁有 tape-out——**C10** 邊界。智慧體提案；oracle 與人類驗證。

**不變量 — 口頭說出來。**
LLM 引導搜尋；它**不會**默默定義未經檢查的可執行行為。每條智慧體路徑都終止於 admit 或經典 fallback。
