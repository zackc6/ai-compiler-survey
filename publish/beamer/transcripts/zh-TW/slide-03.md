# 幻燈片 3：趨勢背景 — 兩個堆疊匯聚

這是§1時代幻燈片——在下一幀的六大趨勢之前設定歷史。

**時間線脊柱。**
在水平軸上從左到右行走：

- **2018–22 — 深度學習編譯器：** TensorFlow XLA、TVM、Glowera 時代。 “AI 編譯器”成熟但**支離破碎的底層**——許多圖形 IR、供應商分叉，沒有單一的智慧體可定址層。
- **2020–23 — RL 健身房：** CompilerGym 及其同類產品 — 不透明健身房環境中的強化學習 (**RL**) 政策。研究豐富；可交付的啟發法很少見。該領域正在離開這個時代。
- **2023–24 — LLM 進入 IR：** 大型模型提出最佳化迭代序列、提示和 IR（**中間表示**）編輯。 mlir 智慧體級工作表明自由重寫是脆弱的；社群轉向受限的行動。
- **2025–26 — 智慧體混合：** 使用工具的智慧體、離線啟發式綜合、具有迴圈驗證的核心智慧體。這是幻燈片上的“今天”——突出顯示的鋼/琥珀色。
- **2027+ — ?** 特意開放。簡報的工作是論證一條“可測試的”混合路徑，而不是預言。

**線下有兩堆。**
左框：**AI 編譯器** — 成熟的堆疊（PyTorch → Inductor → Triton、StableHLO → XLA/IREE），生產合法性和降低，但分散且尚未統一智慧體可呼叫。右框：**編譯器的 AI** — 快速混合增長：Magellan 式離線工程、GEAK 式核心迴圈、Archer 式預測機門控 **PR**（拉取請求）審查。堆疊正在*聚合*，而不是碰撞。

**妙語——大聲說出來。**
下一代**並不**意味著丟棄**LLVM**或**MLIR**（多級紅外）。這意味著使它們**智慧體可定址**：型別化工具、接納門控、測量的判定方向機、版本控制的工件——而確定性降低和構建**CI**（持續整合）可迴歸性仍保留在經典資料面。

結束節奏：兩個堆疊，一個方向 - 對您已發貨的基材進行混合控制面。
