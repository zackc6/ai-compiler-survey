# Slide 5：保留基質，改變控制面

這張幻燈片將六種趨勢轉化為產品決策：**保留**與**採用**。兩列加上反模式橫幅。

**保留 — 經典資料面（左，綠色）。**
這些對於生產編譯器來說是不可協商的：

- **確定性降低** — 相同的 IR 輸入，相同的合法二進位制輸出；預設路徑中沒有靜默的不確定性。
- **庫核心** — 供應商調整的 GEMM、注意力、集體； 智慧體在第一天就“圍繞”他們提出建議，而不是代替他們。
- **構建 CI 可迴歸性** — 每個錄取候選人都經過固定跟蹤；勝利必須在**CI**（持續整合）中重現，而不僅僅是在筆記本中。
- **本地正式檢查** — LLVM IR 切片上的 Alive2 級合法性；足夠便宜，可以按照提案執行。

說出來：您已經信任的執行基礎仍然存在。 智慧體無法繞過合法性，因為模型是有信心的。

**採用——混合控制面（右，鋼）。**
這是 2025-31 年預算的流向：

- **諮詢搜尋** — 最佳化遍歷序列、編譯指示、提示、窄重寫 API — 不是將自由格式的程式碼生成為“opt”。
- **多智慧體編排** — 建議→測量→反映迴圈；工作流程編譯並凍結以供重播。
- **啟發式綜合** — Magellan 級離線進化為可交付的 C++，簽入樹中。
- **配置檔案/驗證者反饋** — 配置檔案、微基準測試和堆疊決策預測機在承認時關閉迴圈。

**反模式——堅決地說出來（餘燼橫幅）。**
用 **不受約束的 LLM 程式碼生成** 替換 `opt`/Inductor — 沒有型別化工具，沒有承認雜湊，沒有經典的回退路徑。這就是 C3/C6 故障模式：使用弱判定預示機的廣泛重寫 API。調查拒絕了地平線 A；保持混合動力（**C6-B**）。

結束節奏：保留基質，改變控制面——將已確定的調查集中在一張幻燈片中。
