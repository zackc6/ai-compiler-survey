# 幻燈片 14：到 2028 年將釋出/不釋出哪些內容

Horizon A具體預測——兩欄加一個藥丸摘要。這就是 **2028** 生產中的“混合勝利”，而不是實驗室演示。

**左 — 預計發貨（綠色）。**
用一個口頭例子來解釋每一個專案符號：

- **智慧體可定址工具介面** — 輸入 **MCP** 級伺服器，編譯模式，允許 Inductor/XLA/MLIR 路徑上的掛鉤。
- **熱路徑專門化，而不是靜默預設全部** - 智慧體在固定跟蹤/熱核心上執行；經典路徑仍然是長尾的預設路徑。
- **Magellan *和* MLGO 均已上線** — 進化 C++ 啟發式 *和* 樹內神經顧問； **C1** 可能會解決違約問題，但兩個家族都堅持嚴肅的組織。
- **嚴肅組織中的 Oracle PR 審查** — Archer 類判定預測機控 **PR**（拉取請求）在智慧體生成的編譯器更改合併之前。
- **覆蓋範圍第一的 ASIC 使能/拉起** — 工作 (d)：新 **NPU**/**ASIC** SKU 上峰值效能之前的正確性表面； TritorX 梯子。
- **Triton 系列初級；多 DSL 崛起** — Triton/Tile/CuTe 共存；沒有單核心 DSL 壟斷。

**右 — *不*發貨（餘燼）。**
將這些視為明確的非目標 - 稍後儲存路線圖引數：

- 無約束的LLM取代了`opt`/Inductor——沒有承認，沒有回退路徑。
- 適用於所有供應商的一個智慧體 IR — 行動式圖表是的； 智慧體訓練表面仍然支離破碎（**C4**）。
- 核心智慧體在融合階梯上一致擊敗渴望的融合 - KernelBench 顯示融合仍然困難；精益求精首先購買正確性。
- 自主微架構流片 — **C10**； 智慧體強調核心/IR，而不是 RTL 替代。

**藥丸線（中心底部）。**
Horizon A 成功 = build-**CI** 門控專業化 + 判定主機 + 凍結工件。如果他們的 2028 年計劃缺少這三項，那麼他們就不是在混合路徑上——而是在演示路徑上。

結束節拍：船欄是可證偽的；使用下一張幻燈片上的檢查點來觀察結算。
