# 幻燈片 14：到 2028 年會出貨／不會出貨什麼

Horizon A 的具體預測——兩欄加底部藥丸摘要。這是 **2028** 生產裡「混合贏了」的樣子，不是實驗室演示。

**左 — 預計出貨（綠）。**
每條配一個口頭例子：

- **智慧體可定址工具介面** — 型別化 **MCP** 級伺服器、編譯 schema、Inductor/XLA/MLIR 路徑上的 admit 掛鉤。
- **熱路徑特化，不是默默預設全部** — 智慧體跑在釘死的 trace／熱核心上；長尾仍走經典預設。
- **Magellan *與* MLGO 並存** — 演化 C++ 啟發式 *與* 樹內神經顧問；**C1** 可能定出預設，但認真組織裡兩族都會留下。
- **認真組織裡的判定預言機 PR 審查** — Archer 級／**llvm-harness** 在智慧體產生的編譯器變更合併前，用判定預言機閘控 **PR**（拉取請求）。
- **覆蓋優先的 ASIC 使能／拉起** — 工作 (d)：新 **NPU**／**ASIC** SKU 先正確性面、再峰值；TritorX 梯子；Zomboss 在研究加速器上的一次編譯對映。
- **Triton 家族為主；Cake IR／Argus DSL 上升** — Triton/Tile/CuTe/Cake/Argus 並存；沒有單一核心 DSL 壟斷（**C4** 更受爭辯）。

**右 — *不*出貨（餘燼）。**
把這些講成明確非目標——後面少吵路線圖：

- 無約束 LLM 取代 `opt`／Inductor——沒有 admit、沒有回退。
- 一個智慧體 IR 打遍所有供應商——可攜圖可以；智慧體訓練面仍碎（**C4**）。
- 核心智慧體在融合梯子上全面贏過 eager——KernelBench 顯示融合仍難；精煉先買正確性。
- 自主微架構流片——**C10**；智慧體壓核心／IR，不是取代 RTL。

**藥丸線（中下）。**
Horizon A 成功 = build-**CI** 閘控特化 + 判定預言機 + freeze 產物。若他們 2028 計畫缺這三樣，就不在混合路上——在演示路上。

收尾：出貨欄可證偽；用後面檢查點看結算。
