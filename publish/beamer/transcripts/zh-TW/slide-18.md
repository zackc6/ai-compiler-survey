# 幻燈片 18：檢查點 C3 / C6 / C9 / C10 — 介面寬度和範圍

四個水平帶——將每個讀作**標題→翻轉（什麼會改變我們的想法）→結果**。這些是範圍限制，而不是研究瑣事。

**C3 — 自由重寫與建議（警告）。**
*今天精益：*狹窄的API - 提示，**ACF**s（高階控制檔案），最佳化迭代序列；經典的塗抹器執行。 *翻轉：*共享公共套件，其中**免費 IR 重寫**（不受約束的 LLM 編輯 MLIR/LLVM）**在 p50 跟蹤上始終擊敗**顧問。 *結果：*行業拓寬了重寫 API — 混合控制面向 C3-A 傾斜。在此翻轉之前，請保留建議（**C6-B**）。

**C6 — 替換 vs 控制面 (ember).**
*今天的精益：*混合——智慧體高於經典的承認/回退路徑。 *翻轉：*生產**預設**路徑，**無**經典承認/回退路徑 - 智慧體輸出是執行事實。 *結果：*智慧體取代了編譯器（**M3**）。調查透過 Horizo​​n B **拒絕**這一點；注意它是偽造者，而不是路線圖。

**C9 — 覆蓋範圍與峰值（鋼）。**
*今天：*核心智慧體在熱門操作上追逐巔峰； 使 SKU 匱乏。 *翻轉：* TritorX → **KernelEvolve** 階梯成為第二供應商晶片的**公共劇本**。 *結果：*產品**SKU**銷售**覆蓋SLA**（服務水平協議-操作表面正確性）**第一**，**效能SLA**第二-與當今的基準營銷相反。

**C10 — 協同設計與自動流片（墨水）。**
*今天：*僅智慧體壓力核心/**IR**/判定預測機；人類+EDA擁有自己的RTL/流片。 *翻轉：*微架構主要是**智慧體提出的** *和* **編譯器判定預測機大規模驗證**。 *結果：*智慧體進入晶片設計工具——遠遠超出了當今編譯器的範圍。地平線 A 船舶列中明確**不**（幻燈片 14）。

關閉節拍：C3/C6繫結介面寬度； C9/C10繫結硬體野心。不要將“快速核心智慧體”與“自主晶片設計”混為一談。
