# 幻燈片 17：檢查點 C2 + C5 — 收益與預設路徑

一張投影片兩個檢查點——左是示意張力圖，右是結算文字。強調：圖**不是**統合分析；它只顯示要避開的指標錯位。

**圖表——示意張力（左）。**
第一柱：**廠商標題約 15%**——精選基準上的最佳核心或 pass 順序。第二柱：**文件熱核心約 2.5%**——文件式代表核心上的中位附近增益。差距就是重點：行銷峰值 ≠ 建置 CI 分佈。別讓現場錨在高柱上。

**現場定義百分位（C2）。**
- **p50** — 第 50 百分位：釘死建置／trace 上的**中位**增益。典型編譯，不是英雄核心。
- **p90** — 第 90 百分位：近尾勝利；仍不是單篇最好的部落格。

**C2 — 智慧體成為預設。**
「智慧體是預設」需要釘死的公開 trace 上的**中位（p50）建置 CI 勝利**——可重現、分佈式證據。一個 KernelBench 英雄、一次 LLVM inliner 勝利、**Argus** 在三個家族上達到 MI300X 組合語言的 99–104%，或 **GEAK v4** 在精選 serving 堆疊上的熱 A/B，都只是*壓力*，不是結算。結算：公開 trace 套件 + 報告的 p50/p90 + 編譯成本，不是只有標題。

**C5 — 線上特化 vs 離線工程。**
兩種共存模式——兩者都可以活：
- **線上特化** — 控制檔、提示、編譯／服務時的 **ACF**（工作 **a**）。
- **離線工程** — Magellan／**MLGO** 離線演化啟發式（工作 **b**）。

產品問題：**哪個是預設旗標？** 發行說明與編譯器驅動預設揭露真路徑——不是主題演講投影片。

**結算（右框底部）。**
釘死的公開 trace + 列出智慧體／控制檔工作流的發行說明。若廠商兩樣都指不出來，就把「預設智慧體編譯器」當願望。

收尾：C2 是分佈；C5 是預設旗標——合在一起測混合有沒有離開實驗室。
