# 幻燈片 21：阻礙 2 — 成本、重播、智慧體何時能跑？

前五阻礙裡的第二項。幻燈片：左到右三階段加箭頭；頁尾是快取鍵與預算公式。口播：走完生命週期，再點出商業上成立的條件。

**Lab — 探索，不出貨。**
互動聊天與工具。GEAK 式生成—評估—反思迴圈、CompileIQ 實驗、Magellan 配方草稿。非確定性花費在這裡可接受。口頭說：lab 是學行動空間的地方——不是按次編譯向客戶收費的地方。

**Product build CI — 預算內批次最佳化。**
智慧體在釘死的 trace 上批次跑，目標明確：每次建置美元上限、延遲天花板、合併前的 Welch 或 canary 閘門。這裡 **SLO**（服務水準目標——可量測目標）遇上 **SLA**（服務水準協議——合約承諾）：你需要為中位數百分比增益命名預算，不是「隨時跑 LLM」。ACCLAIM 與 CompileIQ 級線上 specialize 屬於這裡——只有 admitted 輸出。

**Freeze — 服務時零 LLM。**
控制檔（**ACF** — 進階控制檔／CompileIQ 控制產物，可攜式編譯器旋鈕）、特化核心、演化啟發式進版控。Serving 重播產物；熱路徑沒有智慧體。FlowCompile / AgentFlow freeze 是模式：工作流程編譯一次，部署凍結圖。Horizon A 成功 = build-CI 門控 specialize + oracle + freeze 產物。

**快取鍵與預算行。**
讀頁尾：快取鍵是（IR hash、硬體、編譯器版本、智慧體政策）。預算是每百分點增益的美元。兩者缺一，CI 就無法在升級時回歸智慧體決策——換模型、編譯器 bump、政策變更都會默默失效。

收尾：這在商業上直接打臉「每次建置都跟編譯器聊天」——沒有花費與延遲 SLO 不行。路線圖若說不出智慧體何時跑、什麼要 freeze，你還在 demo 模式。
