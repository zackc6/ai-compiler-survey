# Slide 4: Six active trends

This is the §1 backdrop. On-slide: claim lines dominate; org tags are the tiny mute foot line only. Spoken: claim first, then name examples with organization.

**A — Hybrid guidance, not LLM-as-compiler.**
Free **IR** (Intermediate Representation) rewrite is fragile: mlirAgent from UC Berkeley shows frontier models scoring below identity on IR transforms. **LLM4IR / LaMIR** (ICML 2025; Kent State, HUST, PNNL) is the complementary *understanding* bound: models parse dumped LLVM syntax but fail **CFG** (control-flow graph) edges and instruction-level execution. Winners constrain the action space — hints, **ACF**s (Advanced Control Files), intent sequences (IntOpt), or typed agent IRs (Cake / Argus / **TIRx**). AgentCompile (City University of Hong Kong) emits advisory metadata; templates plus checks admit CUDA. HintPilot (Zhejiang University, with Purdue) inserts compiler-validated pragmas. Meta’s LLM Compiler proposes pass lists that `opt` applies. Say out loud: **LLM-oriented IR** is the agent-visible *face* of the compiler, not a dump of `.ll` and not a new lowering band.

**B — From RL gyms to LLM agents.**
Leave CompilerGym-style opaque neural policies in the gym era. Move to tool-using and multi-agent loops. Compiler-R1 (ISCAS / UCAS) trains tool-calling pass search with **SFT** (supervised fine-tuning) + **RL** (reinforcement learning). Magellan (Google DeepMind / Google) synthesizes shippable C++ heuristics inside LLVM/XLA. FlowCompile (UMass Amherst, MIT, MIT-IBM Watson) compiles structured LLM workflows offline — control-plane substrate, not only chat. Also nod to Auto / AgentFlow for freeze and **ADG** (Agent Dependency Graph) if time allows. **SIGIL** (Michigan) compiles `SKILL.md` → **AG-IR** (agent-graph IR) → a typed harness — *skill* compilation, not kernel admit. **DeepSeek Harness** (`dsh`) is the shipping *runtime* in that family — plugin kernel + session log — not a compiler, not an oracle. Three senses of “skill”: vendor compile packs (CompileIQ) ≠ Agent Skills spec ≠ skill compile / \(\Sigma_t\).

**C — MLIR + Triton as default substrate.**
The production AI path is still classical stacks with org fingerprints: Meta PyTorch → TorchInductor → Triton (OpenAI-origin, community); parallel **StableHLO** / **HLO** (High Level Operations) → OpenXLA/Google XLA and IREE. Peak performance often still sits in NVIDIA vendor libraries, CUDA Tile, CUTLASS, FlashAttention-class kernels. **MLIR** (Multi-Level IR) is the shared mid-IR; product lowering paths diverge by vendor.

**D — Kernel agents go industrial.**
KernelBench (Stanford / Princeton Scaling Intelligence) asks for correct *and* faster kernels; one-shot success is often under 20%, fusion remains hard. On-slide now leads with September 2026: **Hyperloom** (AMD, 21 Sep) is an end-to-end Instinct harness — the kernel phase is delegated to GEAK or KernelForge, and the harness remeasures; author median 1.73× on 16 workloads. **MaxKernel** (Google) writes **Pallas** for TPU; Mosaic still lowers; author 1.58× geometric mean versus XLA on JAXBench. That is peak on a mature compiler, not TritorX-class coverage. **Cake** (NVIDIA / CMU) stays the typed-schedule example. **Argus** (CausalFlow / HKUST / Stanford et al.) is on the mute line: tag functions and compile-time **SMT** (satisfiability modulo theories); authors report 99–104% of MI300X hand-optimized assembly **TFLOPS**. **GEAK v4** is still the earlier AMD e2e loop Hyperloom sits above. Closing beat: refinement still raises correctness more reliably than speed (**C2** open).

**E — Verification enters the loop.**
Stack the oracles: unit and golden tests, numerical checks versus reference, Alive2-class local formal, **Argus** compile-time SMT, **AsmEvo** (AMD) differential checks against the original AMDGPU code object, and **T-LLM Compiler** (Huawei) chaining Alive2 + **CBMC** (C Bounded Model Checker) on PolyBench/C. AsmEvo admits *after* codegen; it is not a proof for all inputs and not a license to free assembly rewrite. Strong locally; weak on **GPU** races and floating-point nondeterminism. Admit for money needs this ladder, not a single check.

**F — Compilers broaden their object.**
Beyond graph→binary: mid-decode diagnosis in generative compilation loops; FMware — prompts, agents, free parameters — as a compile object in Compiler.next (Queen’s University). Magellan (Google) treats agents as in-tree heuristic engineers. Anthropic’s Claude C Compiler shows agent teams *building* a compiler (~100kLoC Rust) — adjacent evidence for agents as compiler engineers, not only compile-time optimizers.

Closing line for the slide: six trends, one pattern — hybrid control plane over classical substrates, with named orgs behind each example.
