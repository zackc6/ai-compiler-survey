# Slide 18: Checkpoints C3 / C6 / C9 / C10 — interface width & scope

Four horizontal bands — read each as **title → Flip (what would change our mind) → consequence**. These are scope limiters, not research trivia.

**C3 — Free rewrite vs advisory (warn).**
*Today lean:* narrow APIs — hints, **ACF**s (Advanced Control Files), pass lists; classical applicator runs. *Flip:* shared public suite where **free IR rewrite** (unconstrained LLM editing MLIR/LLVM) **consistently beats** advisors on p50 traces. *Consequence:* industry widens rewrite API — hybrid control plane thins toward C3-A. Until that flip, hold advisory (**C6-B**).

**C6 — Replace vs control plane (ember).**
*Today lean:* hybrid — agents above classical admit/fallback. *Flip:* production **default** path with **no** classical admit/fallback — agent output is execution truth. *Consequence:* agents replaced the compiler (**M3**). Survey **rejects** this through Horizon B; watch for it as falsifier, not roadmap.

**C9 — Coverage vs peak (steel).**
*Today:* kernel agents chase peak on hot ops; bring-up SKUs starve. *Flip:* TritorX → **KernelEvolve** ladder becomes a **public playbook** for second-vendor silicon. *Consequence:* product **SKU** sells **coverage SLA** (Service Level Agreement — op surface correctness) **first**, **performance SLA** second — inverted from today’s benchmark marketing.

**C10 — Codesign vs auto tape-out (ink).**
*Today:* agents stress kernels/**IR**/oracles only; humans+EDA own RTL/tape-out. *Flip:* microarchitecture primarily **agent-proposed** *and* **compiler-oracle validated** at scale. *Consequence:* agents enter chip-design tooling — far beyond compiler scope today. Explicitly **not** in Horizon A ship column (slide 14).

Closing beat: C3/C6 bound interface width; C9/C10 bound hardware ambition. Do not conflate “fast kernel agent” with “autonomous chip design.”
