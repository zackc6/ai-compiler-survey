- Average ~8.46% IR instruction-count reduction vs -Oz

## Summary

NeurIPS 2025 framework training LLMs to interact with compiler tools and discover pass sequences via outcome-based RL.

## Key takeaways

- First prominent RL-trained LLM compiler agent story
- Tool use is first-class
- Compare carefully to size vs runtime objectives
